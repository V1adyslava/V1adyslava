# Quiz-бот: 25 вопросов → график по 7 уровням

Телеграм-бот проводит диагностику из 25 вопросов и присылает в ответ:

1. Столбчатую диаграмму 7 уровней (зелёное — набранные баллы, красное сверху — сколько не хватает до 100).
2. Текстовую расшифровку с диапазонами дохода и списком «красных» уровней.

## Распределение вопросов

| Уровень | Вопросы      | Сколько вопросов |
|---------|--------------|------------------|
| 1       | 1, 8, 15, 22 | 4                |
| 2       | 2, 9, 16, 23 | 4                |
| 3       | 3, 10, 17, 24| 4                |
| 4       | 4, 11, 18, 25| 4                |
| 5       | 5, 12, 19    | 3                |
| 6       | 6, 13, 20    | 3                |
| 7       | 7, 14, 21    | 3                |

## Подсчёт баллов

Каждый ответ 1–4 переводится в долю заполненности уровня:

| Ответ | Доля |
|-------|------|
| 1️⃣    | 0    |
| 2️⃣    | 0.33 |
| 3️⃣    | 0.67 |
| 4️⃣    | 1.00 |

Итог по уровню = среднее этих долей × 100 (диапазон 0–100).

Пример: Уровень 5 — три вопроса, ответы 4️⃣/3️⃣/2️⃣ → (1 + 0.67 + 0.33) / 3 × 100 ≈ 67.
На графике зелёного 67, красного 33.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# вставьте в .env токен, полученный от @BotFather
export $(grep -v '^#' .env | xargs)

python bot.py
```

После запуска в Telegram отправьте боту `/start`.

## Файлы

- `bot.py` — Telegram-бот (python-telegram-bot v21, async polling).
- `questions.py` — 25 вопросов, распределение по уровням, функция подсчёта.
- `chart.py` — рендер диаграммы через matplotlib.
- `results.py` — формирование текстового результата.
